## 🚀 Overview

A full-stack educational platform built to deliver an interactive learning experience for students and teachers. The system combines modern web technologies with a modular backend architecture to provide fast, secure, and scalable educational services.

---

## 🛠 Tech Stack

### Frontend

* **Next.js 15** (App Router)
* **TypeScript**
* **TailwindCSS + SCSS**

### Backend

* **Node.js + Express.js**
* **PostgreSQL + Prisma ORM**
* **Redis**
* **Socket.IO**

### Infrastructure

* **Ubuntu VPS**
* **Nginx**
* **PM2**
* **Winston Logging**

## ✨ Features

* Algorithmic generation of mathematical exercises.
* Automatic answer validation and instant feedback.
* Grade-based educational content ( 5 - 9 ) with NMT / ZNO preparation.
* Secure authentication with role-based access.
* Real-time notifications and communication.
* Responsive interface optimized for desktop and mobile devices.

## 🏗 Architecture

The application follows a modular **Services / Controllers** architecture, separating business logic from routing and presentation layers. Database interactions are fully type-safe through Prisma, while Redis improves performance by handling sessions and frequently accessed data.
